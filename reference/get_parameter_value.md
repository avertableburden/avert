# Get parameter value

get_parameter_value() is a Get function that extracts data from an
object. Specifically, this function implements an algorithm to get
parameter value. The function returns Parameter (an output object of
multiple potential types).

## Usage

``` r
get_parameter_value(parameter_1L_chr = "first", parameters_ls = NULL)
```

## Arguments

- parameter_1L_chr:

  Parameter (a character vector of length one), Default: 'first'

- parameters_ls:

  Parameters (a list), Default: NULL

## Value

Parameter (an output object of multiple potential types)
