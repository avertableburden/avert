# Launch the Avertable Burden App

Starts the Avertable Burden Shiny application.

## Usage

``` r
run_avert_app(launch_browser = TRUE)
```

## Arguments

- launch_browser:

  Logical indicating whether the app should automatically open in a
  browser.

## Value

Invisibly returns the launched application.

## Examples

``` r
if (FALSE) { # \dontrun{
run_avert_app()
} # }
```
